# ZDT 三维移动滑台上位机

PyQt5 图形化上位机，控制三轴 ZDT 闭环步进电机滑台。三根电机 RS485-A/B 并接在同一根 USB 转 485 总线上，按站号寻址。

- **X 轴**：86 步进，行程 60 cm，默认站号 1
- **Y 轴**：86 步进，行程 40 cm，默认站号 2
- **Z 轴**：57 步进，行程 30 cm，默认站号 3

## 功能

| 模块 | 说明 |
|------|------|
| 连接 | 选串口/波特率/三轴站号，逐轴探测在线状态 |
| 点动 Jog | 六键按住即走、松开即停 + 急停全部（Esc） |
| 定位 Goto | 输入 X/Y/Z 目标 mm，三轴并行相对定位，软限位保护 |
| 回零/设原点 | 电机机械回零（完成后自动设原点）/ 把当前位置设为坐标原点 |
| 示教 | 预设点位表：添加当前点、调出、删除、清空 |
| 标定 | 单轴标定：发已知脉冲数→量实测位移→得 pulses/mm 与 angle/mm |
| 状态 | 三轴电压/电流/速度/坐标 + 使能/到位/失步/保护/回零 灯 |
| 3D 视图 | 行程线框内末端点与轨迹实时显示（无 OpenGL 时回退三视图） |

## 关键设计

- **Z 轴方向约定**：Z 为竖直轴，原点 (0mm) 在长方体**上平面**（顶部回缩位），正方向向下。3D 视图据此把 0mm 显示在顶部、行程末端显示在底部；2D 投影的 Z 轴同样反转（0 在顶）。标定时实测位移 d 向下为正、向上为负。
- **原始协议直发**：开源库 `ZDT_stepper` v0.1.1 的 `Device` 构造用 `get_version` 测连接，但 X42S 二代的 `get_version` 响应为 7 字节（库按 5 字节解析）→ 校验失败 → 设备被判离线。故后台不依赖库的 `Device`，改用 pyserial 直接收发原始帧（FIXED 校验 0x6B，帧格式经真机验证）。库仍随仓提供作协议参考。
- **单总线串行化**：所有串口 I/O 集中在一个后台 QThread，GUI 仅经 Qt 信号交互——杜绝并发冲突与界面卡顿。
- **高效轮询**：每轴每轮仅 1 次往返（`get_sys_status`，31 字节）即取回位置/速度/电压/电流/全部状态标志，约 10 Hz。
- **单位差异**：`move` 指令的脉冲是微步脉冲（16 细分下 3200 脉冲=1 转），而 `real_time_position` 是 65536/转的编码器角度单位。因此标定分两套——`pulses_per_mm`（发 move 用）与 `angle_per_mm`（显示用）——在一次标定中同时测得，互不依赖、不依赖细分读取。
- **定位用相对移动**：`Goto` 按 `Δmm × pulses_per_mm` 发相对移动，避开绝对坐标系单位歧义。

## 安装

```bash
pip install -r requirements.txt
```

环境需 Python ≥ 3.10。控制库 `ZDT_stepper-0.1.1` 已内置，由 `app/__init__.py` 自动加入 `sys.path`，无需 `pip install`。

## 运行

```bash
python main.py
```

无硬件时也能启动：UI 完整、3D 视图显示空行程线框（按需回退三视图）、连接按钮在未选端口时禁用。

## 使用流程（接硬件）

1. **连接**页选对 COM 口 → 连接；状态栏显示在线轴（应 X/Y/Z 全在线）。
2. **标定**页：对每根轴各做一次。选轴→输入脉冲数（默认 5000）→①开始（电机会走一段）→到位后用尺量出实际位移 mm 填入 d→②完成。`pulses/mm` 与 `angle/mm` 自动写入配置。
3. **回零**页：对每根轴点“回零”（机械回零），完成后自动设原点；或用“设原点”把当前位置归零。
4. **定位**页：输入目标坐标 mm → Goto，三轴并行到位；3D 视图画出末端轨迹。
5. **示教**页：走到目标位→添加当前点→之后一键调出复现。

## 配置

存于 `~/.zdt_stage/config.json`：串口/波特率/站号/各轴行程/标定结果/运动参数/预设点位。菜单 文件→导入/导出 可备份。

## 快捷键

- `Esc` 急停全部
- `Ctrl+L` 清轨迹
- `Ctrl+Q` 退出
